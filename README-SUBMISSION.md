# EU Pay QA Engineer Test Assignment — Submission Overview

This technical submission implements comprehensive end-to-end testing, reproduction, and production-grade fixes for all 7 intentional defects in the EU Pay API, covering payment precision, transaction ceiling validation, RFC email conformance, HMAC-SHA256 webhook signatures, event idempotency, table order concurrency, and e-invoicing deduplication. In addition to resolving the intentional bugs, an underlying environment defect in the seeded merchant password hash was discovered and corrected to restore the documented authentication workflow. A robust automated test suite comprising 56 tests was developed using the Node.js native test runner and Supertest, achieving 100% test pass rates across happy paths, negative boundaries, authorization isolation, and WebSocket event emissions. Comprehensive documentation has been authored in `docs/QA_TEST_PLAN.md`, `docs/BUG_REPORT.md`, and `docs/TEST_RESULTS.md` to detail reproduction steps, root causes, security implications, and mitigation strategies.
